# Rare visits and a six-hour player cooldown

Rusty found the initial 20–40 minute interval and one-hour player cooldown too
frequent. Their chosen defaults are a visit every **2–4 hours**, with a **six-hour
cooldown per player**. Server config stores these as 120, 240 and 360 minutes.
These replace the prototype defaults; no build with the old defaults was released.

Random eligible target selection and opportunistic theft remain unchanged.
Outstanding stolen property still receives priority recovery visits, bypassing
the natural-visit cooldown so the owner can get it back promptly.
