# Every carried item is eligible

Rusty: "I think it should be able to steal anything, but be ransomed with the list
you mentioned." There is no theft whitelist. All nonempty player inventory slots
are eligible, including the hotbar, equipped armour and offhand. One item is moved,
with all components retained: damage, enchantments, names and container contents.
Cookie, bread and apple remain the default payment tag. The creature cannot hold
a second claim while the first is outstanding.
